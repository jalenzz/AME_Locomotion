## 2026-07-28 / 第一轮适配后转为三足蹲伏

- 对象：`2026-07-28_16-14-51/model_1300.pt`；配置提交 `e73978c`；同条件运动测试，另测 `vx=0` 站立。
- 改动：地图 2.5×1.5 m、0.1 m、26×16×3；Go2 显式 map dim；CNN 兼容偶数尺寸；直接 yaw-rate；站立比例 5%；扩展非期望接触；足端力阈值 100 N；姿态终止 0.8 rad。
- 指标：vx 0.517 m/s；倾角 0.097 rad；头部接触约 1%；运动/站立机身到平均足端高度 0.164/0.153 m；运动 FL/FR/RL/RR 接触 70.2%/47.3%/8.1%/64.4%；站立 RL 2.3%。
- 落脚：touchdown FL/FR/RL/RR=2278/2176/309/2176；x=+0.124/+0.097/−0.209/−0.176 m；y=+0.075/−0.038/+0.148/−0.137 m。
- 训练：reward 147；episode length 1000；timeout 99.6%；线/角速度奖励 4.898/5、2.926/3；terrain level 0.562（旧训练同迭代 2.168）。
- 结论：头部爬行已改善，但形成低姿态、弃用 RL、前脚偏后且偏窄的高分局部最优；高 timeout 不代表步态合理。
- 根因：`joint_effort_limits=1e9 Nm` 使 `joint_torque_limits` 全程为 0；100 N 足端力项沿用 700 N 权重量级，贡献接近 0；跟踪奖励占主导。
- 状态：保留地图、命令和接触适配；继续修正执行器边界与奖励量级。
